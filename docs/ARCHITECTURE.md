# Architecture decisions

The full design is in `IMPLEMENTATION_PLAN.md` §1–3. This file records decisions and every later change, newest last.

| # | Date | Decision | Reason |
|---|------|----------|--------|
| 1 | 2026-11-15 | A Windows service (virtual account `NT SERVICE\SabhaMujic`) owns playback, the SQLite DB and the protected library folder. Clients are thin. | Playback must survive client disconnects. Volunteers must not reach the files. |
| 2 | 2026-11-15 | File protection is the folder ACL only (service + Administrators), with no encryption at rest. | User choice. Windows administrators are trusted. |
| 3 | 2026-11-15 | App-level roles (`Admin`, `Volunteer`) decide capabilities. The Windows identity is only logged for audit. | Volunteers often share one Windows login. |
| 4 | 2026-11-15 | Desktop ↔ service: named pipe + StreamJsonRpc. Remote ↔ service: HTTPS (Kestrel) + SignalR. Both call one application layer through one `Authorizer`. | Prevents the two transports from drifting into different permission rules. |
| 5 | 2026-11-15 | Remote TLS uses an app-generated local CA, trusted once per iPhone through a `.mobileconfig` profile served on a plain-HTTP bootstrap page. | User choice. Avoids Safari warnings and flaky WebSockets on untrusted certificates. |
| 6 | 2026-11-15 | Smart Loop automatically detects a loop region (self-similarity on beat-synchronous chroma + energy). Low confidence falls back to the whole trimmed track. Admins can override. | User choice. |
| 7 | 2026-11-15 | .NET 10 LTS, self-contained x64. NAudio 2.x. WiX v5 MSI built on GitHub Actions Windows. | LTS support window. Linux cannot build an MSI. |
| 8 | 2026-11-15 | Solution file is `SabhaMujic.slnx` (the .NET 10 default XML format). | Default for .NET 10 `dotnet new sln`. Supported by VS 2022 17.13+ and the .NET 9.0.200+ CLI. |

## Contract versioning
`SabhaMujic.Contracts.ContractVersion.Current` is checked in the handshake (`IAuthApi.HelloAsync`). Bump it on any breaking change to DTOs or RPC signatures.

## Playback state machine
States: `Idle`, `Loading`, `Playing`, `Paused`, `Crossfading`, `Stopped`, `Error`.
The transition table is defined in code in `SabhaMujic.Core.Playback.PlaybackStateMachine` and covered exhaustively by `PlaybackStateMachineTests`. The code is the spec.

| 16 | 2026-11-15 | Desktop view models live in the cross-platform `SabhaMujic.Desktop.ViewModels` (net10.0) library. WPF only holds views and adapters. `DemoSabhaClient` is a dev/demo tool, only used with `--demo`. | View models stay unit-testable on Linux. |
| 17 | 2026-11-15 | The wire protocol (JSON-RPC method names `"<Interface>.<Method>"`, header-delimited framing with a size guard, errors as code -32000 carrying `ErrorInfo`) lives in `SabhaMujic.Client/Rpc`. Server references Client, so both sides share it. | One definition of the protocol. No drift between service and desktop. |
| 18 | 2026-11-15 | `ApiSession.Run` is the authorization choke point. It finds the operation via `[CallerMemberName]` + `OperationMap`, re-validates the session, then calls `Authorizer.Demand` before the body runs. It's reused by the M5 remote. Unexpected exceptions become `Internal` with a fixed message. | Structurally hard to bypass. An exhaustive real-pipe test (51 methods × 3 roles) also asserts that denials have zero side effects. |
| 19 | 2026-11-15 | Auth policy: 5 failed logins per user name and 50 globally per 5 min. Unknown users still run one PBKDF2 check. Desktop and remote user sessions slide over 12 h. Device tokens last until revoked. A password reset revokes the target user's sessions. You can't delete yourself or the last admin. Pairing: 5 failures per caller and 20 globally per 5 min. | Brute-force resistance for 6-digit codes and PINs. |
| 20 | 2026-11-15 | `ErrorCode.Unavailable` (client-side: not connected or connection lost) was added, so `Internal` means only genuine server faults. | Proposal from the M3a review. |
| 21 | 2026-11-15 | Remote web app: plain ES modules + JSDoc, type-checked with `tsc --checkJs`, embedded as resources in Server. The SignalR browser client is vendored. This replaces the plan's "TypeScript + Vite". | No build step at install time and no Node on the Windows build path. Same type safety. |
| 22 | 2026-11-15 | The pairing QR encodes `http://<ip>:8080/#code=NNNNNN`. The fragment is never sent over plain HTTP, and the bootstrap page carries it to `https://…/pair#code=`. Device tokens live in HttpOnly + Secure + SameSite=Strict cookies, with a custom-header + Origin CSRF check. The remote rejects non-private source IPs. | Keeps codes and tokens off the wire and away from JS. Trust in the CA is TOFU on the local network; its fingerprint is shown on the desktop and on the bootstrap page for comparison. |
| 23 | 2026-11-15 | Audio engine (M1) as built: NAudio 3 `WasapiPlayer` (`WasapiOut` is obsolete in NAudio 3). The mixer plays buffered "voices", each decoded about 1 s ahead on a background thread, so the render path never touches disk or locks. Features use a 21.3 ms hop, a DP beat tracker and ±8-beat seam scoring. Loop seams use correlation-compensated equal-power gains. Fallback below confidence 0.4 uses a 2 s crossfade. Volume gain = v². | Accuracy of the ±20 ms refinement, no +3 dB swell on correlated seams, and a render path with zero allocations (measured). |
| 24 | 2026-11-15 | First-run setup: when no accounts exist, the desktop app offers "Create administrator". The service allows it only for a desktop-pipe caller whose token is an **elevated** local Administrator (the installer's finish step launches the app elevated). It's never allowed from the remote. Contract: `IAuthApi.IsSetupRequiredAsync` + `CompleteInitialSetupAsync`, `Operation.InitialSetup`. | No default passwords, and no secret files on disk. Under UAC, a non-elevated admin token doesn't count. |
| 25 | 2026-11-15 | `SabhaHost` (Server/Hosting) is the single composition root used by the Windows service, DevHost and the integration tests. Extra transports plug in as `IHostedComponent`s (start after the core, stop before it). On first boot, persisted settings override engine options. | One wiring path, tested on Linux end to end. |
| 26 | 2026-11-15 | Windows ACLs: `data`, `library` and `uploads` have a protected DACL (SYSTEM, Administrators, `NT SERVICE\SabhaMujic` full control; nothing else). The pipe DACL gives Authenticated Users ReadWrite without CreateNewInstance, and `FirstPipeInstance` is set. The client opens the pipe with exactly ReadWrite. | Volunteers can't read the files or squat the pipe. |
| 27 | 2026-11-15 | Known gaps, deferred to M6: a loop override or re-analysis applies the next time the track is opened, not to the voice already playing; restore starts Stopped at the current item (no in-track position), with new queue item ids; seam correlation, fallback flag and tempo aren't persisted, so after a restart Ready analyses use correlation 0. | Need small engine APIs (`RefreshTrackAsync`, `RestoreQueueAsync`) and data migration 0002. Tracked in PROGRESS. |
| 28 | 2026-11-15 | Remote as built (M5): `RemoteHost` (Kestrel) with a bootstrap site on HTTP (4 paths only) and HTTPS for the app, `/api` (pair/me/logout/uploads) and the `/hub` SignalR hub (method names = contract names without "Async"). Every call goes through a per-connection or per-request `ApiSession`. The leaf certificate is re-issued live via `ServerCertificateSelector`, and the CA/leaf keys persist through `ISecretProtector`. Strict CSP (no `unsafe-*`). Device cookie `__Host-SabhaMujic`. | Builds on #21/#22. Exhaustive hub + HTTP authorization tests, 7 browser e2e tests. |
| 29 | 2026-11-15 | Installer: **WiX 5.0.2** (MS-RL), built only on Windows CI. WiX 6/7 are not used. | WiX 6+ ships under the Open Source Maintenance Fee EULA (`requireLicenseAcceptance`), which would be a licensing obligation for the project. 5.0.2 has none and matches the approved plan. |
| 30 | 2026-11-15 | Amends #24: an MSI's "launch app" step runs unelevated, so the desktop setup screen offers **"Restart as administrator"** (relaunch with `runas`, which triggers UAC) when the service answers Forbidden. | Keeps first-run setup a one-click flow without elevating the whole UI permanently. |
| 31 | 2026-11-16 | The remote runs inside the service as the first `IHostedComponent` (`RemoteComponent`). CA/leaf keys live in `<DataRoot>\certs` (ACL'd like `data`) and are protected by `DpapiSecretProtector`: direct `CryptProtectData`, machine scope + app entropy, so no WinForms/WPF framework dependency in the service. Invalid values stop startup with a clear message. | One process, one ACL model, and keys unreadable outside the machine and service. |
| 32 | 2026-11-16 | Phone "Sign out" unpairs the device: it revokes its own device record and sessions without admin rights, sends `SessionEnded`/`DevicesChanged`, and is audited as `device.logout`. `PairingCodeDto.CaFingerprint` (an additive init property; contract stays v1 until release) is shown on the desktop pairing panel. | No orphaned tokens. | 34 | 2026-11-16 | Data-root hardening: `DataRootGuard` refuses junctions, symlinks and files in place of the root or `data/library/uploads/certs/logs` (and the store subfolders) before writing anything. `WindowsDataRootGuard` sets owner Administrators and exact protected DACLs (Users: read on root, read-only on `logs`). | 36 | 2026-11-16 | Reliability fixes from QA. Playback-state saves retry with backoff (1→30 s) and flush on stop. A failed explicit play request never interrupts current playback.
